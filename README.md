# Duplex · Control token 核对

当前页面仅展示双轨波形、导出分块文本及 control token；提供逐块、逐页和连续试听。音频、文本、排程及原始训练记录未修改。原来的质量评分、ASR 对照、完整话轮、事件/CUT 标记、对齐详情和原始 JSON 展示均已移出页面。

## 统计与定位

- 默认使用原来随机抽取的 10 条，不重新抽样。按原始训练记录逐条计数，连续相同 token 分别计入，不能当成交互事件数。
- 卡片显示当前样本数量和本组 10 条合计；点击卡片或类型选择器可筛选。
- 支持上一个/下一个、按第几处跳转、位置列表逐条点击，以及按块编号定位。位置列表每组 8 条。
- Control 行按助手目标所在的物理时段展示。普通记录来自上一输入块；助手开场空输入对应首块。User 开场的第零块没有助手目标记录时显示 —，不推断标签。
- 末条没有目标音频、决策时段在完整音轨之外的记录照常计数，在“会话末尾”单独展示；不伪造波形或补音频。
- `?demo=<id>&token=<URL 编码后的 token>` 筛选并定位首处，`&record=<训练记录编号>` 定位特定记录，`&chunk=<物理块编号>` 定位音频块。

`assets/catalog.random10.json` 保存本组及每条的派生计数。实际页面内当前样本统计从原始 `records` 重新计数。全部 10 条共 25,337 条：listen 7,839、wait 43、bc 44、speak 16,870、idle 541。

## 数据保留

音频仍使用现有的无损压缩 PCM，按需加载所选样本；不调用生成、ASR、对齐或排程。展示文本直接读取 `annotations_json.timeline_chunks` 的导出文本，不在网页重分词或重排。旧 assets、原始 chunks.json 和 Git 历史保持不变，上一批链接 `?set=previous` 仍可打开带分块的条目。

字体为 Duplex Chunk Sans（Noto Sans CJK 子集），许可见 `assets/OFL.txt`。
