## 当前响度对比

默认播放“调整后”，可在同一块切换“调整前”。此版本复用上述排程的原始话轮音频，只有固定增益发生变化；全部话轮位置、CUT、320 ms 块、文本和末尾补零完全相同，没有再次调用模型。

普通话轮按角色汇总 LUFS 平衡，目标 −22 LUFS，保留话轮间自然变化；短反馈按重叠实际发声帧的 K 加权能量处理，目标比主话轮低 1 dB，容差 ±1 dB。每条音频只乘固定系数，总增益限制 ±9 dB。双轨和相加混音共用峰值保护，浏览器不做额外响度处理。

独立 FFmpeg 检查：普通 User 为 −19.7 → −22.0 LUFS，Assistant 为 −25.1 → −22.0 LUFS；混音真峰值 −2.0 dBTP。短反馈 u005（块 #133，42.560 秒）从比同时发声的 User 低 8.4 dB 调到低 1.0 dB；这里用有效帧能量比较，不把短片段当作可靠 LUFS。

响度计算与共同峰值保护耗时 2.42 秒，读取、渲染与 JSON 导出共 15.05 秒，额外只读评分 24.62 秒。133 项代码测试及实际 demo 的时间戳、文本、末尾补零、断点复用验证通过；数值检测不等于人工自然度听评。

## 使用

点击任意块选中，再点击“播放此块”；也可播放本页或从所选位置连续播放。双轨模式为左声道 User、右声道 Assistant，也可分别独听。交互下拉框和事件标签用于跳转。`?chunk=133` 可直接定位本次短反馈。切换音频版本会停止播放并保持位置，两个版本使用相同幅度刻度。

波形上方显示该块的前置文本。下方的对齐片段显示真实声学时间，二者应分开核对：无新文本的块仍可能有语音延续。展开 JSON 可查看所选物理音频块分别对应的 User 输入记录、Assistant 目标记录、控制标签和文本结束标记。

## 本地运行与发布

```bash
python3 -m http.server 8765 --bind 127.0.0.1
```

访问 `http://127.0.0.1:8765/`。无需 npm 或构建步骤。GitHub Pages 从 `main` 分支根目录发布，保留 `.nojekyll`。

## 文件

- `index.html`：分块波形、文本、试听和 JSON 检查界面。
- `assets/demo.json`：展示数据，包括真实音频块、导出文本、训练记录、对齐片段、事件、两个版本的波形 min/max 和响度测量。去掉服务器绝对路径。
- `assets/user.pcm.deflate`、`assets/assistant.pcm.deflate`：调整后的 16-bit little-endian 单声道 PCM，无损 deflate 压缩；`assets/user.before.pcm.deflate`、`assets/assistant.before.pcm.deflate` 保留调整前版本。只加载被试听的版本；浏览器使用同一个 AudioContext 时钟按采样区间播放，不额外归一化、重采样或淡入淡出。
- `assets/demo-sans.woff`：Noto Sans CJK 字形子集，命名为 Duplex Chunk Sans；许可证见 `assets/OFL.txt`。
- `assets/demo.wav`：上一版页面保留的试听备份，不参与当前页面播放。

公开展示文件不包含 API 配置、模型、角色克隆参考录音、原始数据索引或服务器路径。原始场景来源为 OpenAssistant/oasst1（Apache-2.0），当前页显示 pipeline 生成的对话产物。
